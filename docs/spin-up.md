# Spin-up

How to turn a generated repository into a deployed, signed-in app. Run the steps in order; each row says what to run, what you should see, and whether anyone has run it yet.

## What you are agreeing to

Read this before step 1. By spinning up a project you accept that:

1. `prod` is reachable at a public `workers.dev` URL from the first deploy
2. on Workers Paid a flood costs money before anyone acts and the required volume alert says so
3. previews and `prod` share one Cloudflare account and one token
4. the `admin` profile mints tokens for the whole account
5. there is no self-service account recovery (no password reset, no email verification) until the email add-in is on, the passkey nudge at sign-up is the mitigation and the one-line email switch the exit
6. on a private repository nothing native stops a committed secret (secret scanning and push protection are 422 on private Pro and absent on private Free), so the ignore list and the hook are the only control for `.env`, `.env.local`, `.env.op`, `.alchemy/` and the sortui key, asserted by the ignore test

## Prerequisites

Bun at the `packageManager` pin in `package.json`, `gh`, Node `>= 22.12`, a GitHub account on any plan (the tier is detected and reported, never typed), a Cloudflare account on Workers Paid (the password hash costs about `115 ms` of CPU per sign-in against the Free plan's `10 ms` limit, so the bootstrap refuses a Free account), and the one install click per app: the GitHub App and hosted Renovate are each installed on the new repository with one click unless both are already installed on all repositories.

## The tags

Every step carries exactly one tag, and `bun run check` fails a row that breaks the standard.

- `verified`: a unit ran the command and saw the signal. Rests on holds the run: `PR #<n> proof <m>` or a commit sha.
- `unproven`: not yet run, or only read, dry-run or proved in part. Rests on names the `I-NN` issue of the Build plan in `docs/architecture.md` that will prove it. An `unproven` row may name a command that does not exist yet.
- `note`: a recorded fact, not a step to run.
